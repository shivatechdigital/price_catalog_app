# App Store Review Notes (Permissions)

Use the following notes in App Store Connect review details:

## Camera
The app uses camera access only for product management. Admin users can capture product images directly while creating or updating catalog items.

## Photo Library
The app uses photo library access to select existing product images and attach them to catalog listings.

## Photo Library Add
The app saves generated/shared catalog images to the photo library only when the user initiates export or share.

## Notifications
The app uses push/local notifications to inform users about new requirements, requirement approval/rejection updates, and important trading actions.
